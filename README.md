# 微电子2604班活动指南

这是用于介绍班级活动的静态展示页。所需文件全部位于本目录，无需安装依赖，也没有报名或信息收集机制。

首页默认展示班级活动主题，点击“探索活动”后进入活动列表。列表支持搜索、分类筛选和活动详情查看。

## 预览

直接用浏览器打开 `index.html`。也可在本目录执行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000`。

## 更新活动

编辑 `activities.js`。`category` 为 `lecture`（讲座类）、`core`（核心项目）、`small`（小活动）或 `required`（必做项目）。

`id` 使用稳定的文本标识，如 `lab-visit`，与原始策划案编号无关。不要在数据中保存展示编号；页面按照分类内的活动顺序，从 1 开始生成编号。分类及颜色顺序为讲座类（蓝）、核心项目（黄）、小活动（白）、必做项目（红）。

`summary` 说明活动做什么，`steps` 展示活动流程。`time`、`location` 尚未确认时保持空字符串，由页面显示待确认提示。公开数据只包含活动介绍、流程、时间和地点等展示信息，不设置报名链接、报名状态或活动完成状态字段。待确认的细节不要当作既定安排填写。

## 本地维护与隐私

项目根目录 `.gitignore` 仅允许本目录和 `.gitignore` 被 Git 收录，同时排除本目录中的原始文档、表格、PDF、环境配置及临时文件。原始资料应始终留在本目录之外。

尚未建立 Git 仓库时，先在项目根目录执行 `git init`。然后执行：

```sh
git add .gitignore page
git diff --cached --stat
git status --short
```

确认暂存区仅含网页文件后再 commit。Git 忽略规则不影响此前已跟踪的文件；若使用已有仓库，请同时检查已跟踪文件。
